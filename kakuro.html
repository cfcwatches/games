How to play Kakuro

Kakuro is a number crossword. The dark cells hold clues: the number in the top right is the total for the run of white cells to its right, and the number in the bottom left is the total for the run below. Fill every white cell with a digit from 1 to 9 so that each run adds up to its clue and no digit appears twice in the same run.

Some cells are pre-filled (tinted and locked). They are there so that every puzzle has exactly one solution, and they make a handy place to start.

Controls

Tap a cell, then tap a digit. Switch on Notes to pencil in candidates. On a keyboard, use the number keys, the arrow keys, Backspace to erase and N for notes. Check highlights any wrong cells, and Hint fills in the selected cell (hinted games do not set a best time).

Tips

  • Where an across and a down run cross, the digit must satisfy both. Use the shared cell to narrow down each run.
  • A short run with a very small or very large total has few options. Start there.
  • Keep notes on cells with two candidates and look for a run that forces one of them.
